# Design System

Use this design system for all UI work. Do not change content, layout, or page structure unless asked.

## Font
Montserrat (Google Fonts, weights 300, 400, 600, 700) for everything.

## Colors (define as CSS variables)
- --color-primary: #D94948 (buttons, accents)
- --color-navy: #011627 (footer, dark sections, headings)
- --color-text: #666666 (body text)
- --color-bg: #FFFFFF
- --color-bg-soft: #F9F8F8
- --color-border: #EAEAEA
- --color-secondary: #61CE70 (CTA band, optional)
- White text over hero images

## Font sizes (desktop)
- Hero headline: 30px, bold, uppercase, white
- Hero eyebrow: 14px, bold
- H1: 28px, bold
- H2: 24px, semi-bold
- H3 (card/feature headings): 20px, bold, uppercase
- Project card titles: 14px, bold
- Body: 13px, line-height 1.55, regular/light
- Nav links: 13-14px
- Buttons: 13px, bold, uppercase
- Footer headings: 17px, regular, white
- Footer text/links: 13px, white

## Mobile
Hero and H1 about 22px, H2 about 20px, body at least 14px.

## Buttons
Pill-shaped (border-radius 50px), background var(--color-primary), white bold uppercase text, padding 14px 28px, slightly darker on hover.

## Sections
- Hero: full-width image, white text, red Contact button
- Content: white background, centered navy headings, gray body text
- CTA band: green background, navy heading, red button
- Footer: navy background, white text
